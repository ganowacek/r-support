ggplot2 is based on the grammar of graphics — the idea that you can build every graph from the same components: a data set, a coordinate system, and geoms, visual marks that represent data points.

📄 Based on the Data Visualization cheatsheet · ggplot2 4.0.3

The template

Every ggplot2 chart follows the same basic recipe. Only data, the geom function, and its mapping are required — everything else falls back to sensible defaults.

ggplot(data = <DATA>) +
  <GEOM_FUNCTION>(
    mapping = aes(<MAPPINGS>),
    stat = <STAT>,
    position = <POSITION>
  ) +
  <COORDINATE_FUNCTION> +
  <FACET_FUNCTION> +
  <SCALE_FUNCTION> +
  <THEME_FUNCTION>
ggplot(data, aes(x, y))
Begin a plot that you finish by adding layers (geoms) with +.
last_plot()
Returns the last plot that was displayed.
ggsave("plot.png", width = 5, height = 5)
Saves the last plot as a 5”×5” file. File type is inferred from the extension.

Common aesthetic (aes) values

Aesthetic Values
color / fill a string, e.g. "red", "#RRGGBB"
linetype integer or name: 0=“blank”, 1=“solid”, 2=“dashed”, 3=“dotted”, 4=“dotdash”, 5=“longdash”, 6=“twodash”
size integer, in mm (point/text size)
linewidth integer, in mm (line width)
shape integer 0–25, a shape name, or a single character, e.g. "a"

Geoms

A geom function represents your data as a visual layer. Its aesthetic arguments map variables to visual properties like position, size, and color.

One variable

Continuous: geom_area(stat = "bin"), geom_density(kernel = "gaussian"), geom_dotplot(), geom_freqpoly(), geom_histogram(binwidth = 5), geom_qq(aes(sample = x))

Discrete: geom_bar()

Two variables

Both continuous: geom_label(), geom_point(), geom_quantile(), geom_rug(), geom_smooth(method = lm), geom_text()

One discrete, one continuous: geom_col(), geom_boxplot(), geom_dotplot(), geom_violin()

Both discrete: geom_count(), geom_jitter()

Continuous bivariate distribution & continuous function

geom_bin2d(binwidth = c(0.25,500)) geom_density_2d() geom_hex() geom_area() geom_line() geom_step(direction = "hv")

Visualizing error & maps

geom_crossbar() geom_errorbar() / geom_errorbarh() geom_linerange() geom_pointrange() geom_sf(aes(fill = ...))

For maps, read spatial data with sf (e.g. sf::st_read(...)) and draw it with geom_sf().

Three variables

geom_contour(aes(z = z)) geom_contour_filled(aes(fill = z)) geom_raster(aes(fill = z)) geom_tile(aes(fill = z))

Graphical primitives & line segments

geom_blank() geom_curve() geom_path() geom_polygon() geom_rect() geom_ribbon() geom_abline() geom_hline() geom_vline() geom_segment() geom_spoke()

Stats

A stat is an alternative way to build a layer: it builds new variables to plot (e.g. count, proportion) before a geom draws them. Every geom has a default stat, and every stat has a default geom — you can override either one.

# Equivalent ways to draw a bar chart of counts
ggplot(df, aes(x)) + geom_bar()
ggplot(df, aes(x)) + geom_bar(stat = "count")
ggplot(df, aes(x)) + stat_count(geom = "bar")

stat_bin() stat_count() stat_density() stat_bin_2d() stat_bin_hex() stat_contour() stat_summary() stat_summary_2d() stat_ecdf() stat_quantile() stat_smooth() stat_ellipse() stat_function() stat_qq() stat_unique()

Scales

Scales map data values to the visual values of an aesthetic. Override a default with scale_<aesthetic>_<type>(), e.g. scale_fill_manual().

n <- d + geom_bar(aes(fill = fl))
n + scale_fill_manual(
  values = c("skyblue", "royalblue", "blue", "navy"),
  limits = c("d", "e", "p", "r"),
  breaks = c("d", "e", "p", "r"),
  name = "fuel", labels = c("D", "E", "P", "R")
)
Purpose Functions
General purpose scale_*_continuous(), scale_*_discrete(), scale_*_binned(), scale_*_identity(), scale_*_manual(values = c()), scale_*_date(), scale_*_datetime()
X & Y location scale_x_log10(), scale_x_reverse(), scale_x_sqrt() (and y equivalents)
Color/fill — discrete scale_fill_brewer(palette = "Blues"), scale_fill_grey()
Color/fill — continuous scale_fill_distiller(palette = "Blues"), scale_fill_gradient(low, high), scale_fill_gradient2(low, mid, high), scale_fill_gradientn(colors = ...)
Shape & size scale_shape(), scale_shape_manual(values = c()), scale_size(), scale_radius(range = c()), scale_size_area(max_size = ...)

Coordinate systems

coord_cartesian(xlim, ylim)
The default cartesian coordinate system, with optional axis limits.
coord_fixed(ratio = 1/2)
Cartesian coordinates with a fixed aspect ratio between x and y units.
coord_flip()
Flip cartesian coordinates by switching the x and y aesthetic mappings.
coord_polar(theta = "x")
Polar coordinates.
coord_trans(y = "sqrt")
Transformed cartesian coordinates.
coord_sf()
Ensures all layers share a common Coordinate Reference System — use with geom_sf().

Position adjustments

Position adjustments determine how geoms that would otherwise overlap get arranged.

position = "dodge"
Arrange elements side by side.
position = "fill"
Stack elements and normalize height to 100%.
position = "jitter"
Add random noise to x/y position to reduce overplotting.
position = "nudge"
Nudge labels away from their points.
position = "stack"
Stack elements on top of one another.

Recast a position as a function to pass extra arguments, e.g. s + geom_bar(position = position_dodge(width = 1)).

Faceting

Facets divide a plot into subplots based on the values of one or more discrete variables.

facet_grid(. ~ fl)
Facet into columns based on fl.
facet_grid(year ~ .)
Facet into rows based on year.
facet_grid(year ~ fl)
Facet into both rows and columns.
facet_wrap(~ fl)
Wrap facets into a rectangular layout.

Let axis limits vary across facets with scales = "free" (or "free_x" / "free_y"), and relabel facet strips with labeller = label_both or label_bquote(...).

Labels and legends

t + labs(
  x = "New x axis label",
  y = "New y axis label",
  title = "Add a title above the plot",
  subtitle = "Add a subtitle below title",
  caption = "Add a caption below plot",
  alt = "Add alt text to the plot"
)

t + annotate(geom = "text", x = 8, y = 9, label = "A")

p + guides(x = guide_axis(n.dodge = 2))   # avoid crowded axis labels
n + guides(fill = "none")                 # hide a legend
n + theme(legend.position = "bottom")     # place a legend
n + scale_fill_discrete(name = "Title", labels = c("A","B","C","D","E"))

Themes

theme_bw() theme_gray() (default) theme_dark() theme_classic() theme_light() theme_linedraw() theme_minimal() theme_void()

Customize any theme element — axis, legend, panel, or facet properties — with theme():

u + theme(plot.title = element_text(...))
u + theme(panel.background = element_rect(fill = "blue"))

Zooming

coord_cartesian(xlim = c(0, 100), ylim = c(10, 20))
Preferred. Zooms the view without clipping — data outside the range is still used for stats like smoothing.
xlim(0, 100) + ylim(10, 20)
Zooms with clipping — removes data outside the range before any stats are computed. Same effect as setting limits on scale_x_continuous() / scale_y_continuous().
