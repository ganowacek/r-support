Why the tidyverse?

Every reference on this site centers on the tidyverse, a collection of R packages designed to work together around a shared philosophy: data should be tidy — each variable in its own column, each observation in its own row — and functions should be predictable, pipeable, and human-readable.

A typical R workflow

  1. Set up your project. Open RStudio, create a Project (File > New Project), and organize your scripts, data, and outputs. See RStudio IDE.
  2. Import your data. Read CSVs, Excel files, or Google Sheets into tibbles with read_csv(), read_excel(), or read_sheet(). See Importing Data.
  3. Clean and reshape it. Filter rows, select columns, create new variables, and summarize groups with dplyr verbs. See Transforming Data.
  4. Wrangle text and categories. Clean up messy text with stringr and tame categorical variables with forcats. See Strings and Factors.
  5. Visualize and share. Build layered plots with ggplot2, then knit results into a report with R Markdown. See Data Visualization.
